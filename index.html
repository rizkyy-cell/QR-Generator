📖 Cara Penggunaan

  1. Pilih menu QRIS Merchant untuk mencetak kode pada papan akrilik toko, atau QR Biasa untuk cetak barcode umum.
  2. Masukkan link URL atau upload gambar yang valid.
  3. Isi data nama toko dan identitas jika diperlukan.
  4. Klik "Generate" lalu tekan tombol Download.

ℹ️ Tentang Aplikasi

Aplikasi ini dibuat khusus untuk mempermudah pembuatan cetakan kartu QR Code beresolusi tinggi (HD) secara instan. Hasil download dijamin tajam dan siap langsung di-print.
